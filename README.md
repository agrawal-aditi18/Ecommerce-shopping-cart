# 🛒 E-Commerce Shopping Cart

A beginner-friendly **E-Commerce Cart** project built with **HTML**, **CSS**, and **JavaScript**.  
It features dynamic product listing, a working shopping cart, item deletion, and persistent cart data using `localStorage`.

---

## 🔮 Features

- 🧾 Dynamic product listing with JS
- 🛍️ Add products to your shopping cart
- 🗑️ Remove items from the cart
- 💰 View total cart amount in real time
- 💾 Cart data saved using `localStorage`
- 🔄 Cart remains even after page refresh
- ✅ Checkout button clears the cart
- 🎨 Simple and responsive design

---

## 🖥️ Technologies Used

- HTML5  
- CSS3  
- JavaScript (ES6+)  
- LocalStorage API
